# ASCII Portrait Generator

Transform photos into ASCII art using keyboard characters.

## Features

- 70+ character grayscale mapping
- Adjustable width (50-500 characters)
- Brightness & contrast controls
- Real-time preview
- Invert option
- Download as text file

## Usage

1. Open `index.html` in a browser
2. Click "Start Generating"
3. Upload an image or use default
4. Adjust settings and click "Generate ASCII"
5. Download result

## Controls

- **Width**: Character count (detail level)
- **Brightness**: -100 to +100
- **Contrast**: 50% to 200%
- **Font Size**: 4px to 16px
- **Invert**: Reverse character mapping

## Files

- `index.html` - Main app
- `style.css` - Styling
- `script.js` - Conversion logic
