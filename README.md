# ASCII Portrait Studio

Transform photos into detailed ASCII portraits with a professional creative studio. This modern upgrade features multiple character sets, color modes, real-time preview, and multiple export formats.

## Features

- **High-Quality Rendering**: Improved tonal mapping with gamma correction and aspect ratio preservation
- **Multiple Character Sets**: Minimal, Standard, Detailed, and Custom character ramps
- **Color & Monochrome**: Classic monochrome, terminal green, amber, cyberpunk, and full-color ASCII
- **Live Preview**: Real-time updates with intelligent debouncing
- **Advanced Controls**: Brightness, contrast, gamma, output width, and character customization
- **Multiple Export Formats**: Download as TXT, PNG, or SVG. Copy to clipboard instantly
- **Professional Studio UI**: Responsive design with landing page, editor workspace, and before/after comparison
- **Privacy First**: All processing happens locally in your browser - no uploads required

## Usage

1. Open `index.html` in a browser
2. Click "Start Creating"
3. Upload an image via drag-and-drop or file picker
4. Adjust settings and see live preview
5. Export as TXT, PNG, or SVG

## Keyboard Shortcuts

- **Ctrl/Cmd + C**: Copy ASCII to clipboard
- **Escape**: Close dialogs and dropdowns

## Files

- `index.html` - Main application
- `style.css` - Styling
- `script.js` - ASCII conversion and UI logic
